# ✉️ AI Email Generator

An AI-powered email generator built with Streamlit and Groq API.

The application allows users to generate professional emails by
providing the recipient, purpose, tone, length, and additional details.

## 🚀 Features

- Generate professional emails using AI
- Multiple email tones
- Short, medium, and detailed email lengths
- Custom email purpose
- Additional details support
- Simple and beginner-friendly interface
- Groq API integration
- Streamlit web interface
- Secure API key management using Streamlit Secrets
- Easy deployment through GitHub and Streamlit Community Cloud

## 🛠️ Technologies Used

- Python
- Streamlit
- Groq API
- GitHub
- Streamlit Community Cloud
